# Interview Buddy

Started October 4, 2026 during the Hacktoberfest Weekend Challenge.

Goal: a minimal local study companion for Raj, the user's real friend preparing for
Java backend developer interviews. User specified medium difficulty. The current scope
is concept refreshers and backend fundamentals, not a complete Java backend curriculum.
The user's confirmation does not establish that Raj has tested it; feedback is pending.

Stack: React + Vite, FastAPI, httpx, uv, Ollama, Qwen3 4B.
Modes: Explain, Explain simpler, Show example, Interview answer.
Prompts target medium difficulty Java backend practice; examples use Java or SQL.
Starters include Spring Boot constructor injection and Java HashMap.
No database, login, RAG, agents, paid APIs, or extra infrastructure.

then demo video and DEV draft using the official submission template.
